poly solAce

This is my newest project, called Poly Solace for now. Right now, the player is able to generate a low-poly world at random. The current platform for the game has recently changed to Virtual Reality (VR). The premise revolves around the player being a God of this low-poly world. They will be able to create, destory, or just simply observe the world. My focus has been on the map generation for awhile now, I am trying my best to perfect this portion of the game. I need to create a strong foundation for the core-gameplay to allow for easier additions later on.

Poly Solace is a large project, it requires quick procedural generation, intelligent AI, intuitive user controls, large library of 3D models, music, and extensive optimization
